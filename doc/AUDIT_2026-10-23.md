## 2. Executive summary

- **Verified:** `npm test` 266/266 pass. `tsc --noEmit` has 0 errors. `npm run build` succeeds. Parser throughput is ~20.7 µs/call over a 12-string sample.
- **Most important confirmed defects:**
  1. Polynomial ReDoS in the HGVSc/HGVSp regexes: an 8,000-space input freezes parsing for ~1.1 s, and 50,000 spaces ran for >20 s before I killed it.
  2. Prose false positives: `Figure 3`, `Day 14`, `Table 1` and `Patient 101` parse as valid c. variants. `A1B2`, `C3PO` and `R2D2` parse as protein variants.
  3. Build handling is inconsistent across URL builders (gnomAD, UCSC, SpliceAI and Franklin ignore `parsed.genomeBuild`). In the side panel, a sync effect masks this except when the user manually toggles the build.
  4. Accessibility: clickable `<div>` rows with no keyboard support.
  5. Undocumented `clipboardRead`/`clipboardWrite` permissions, plus stale docs.
- **Scope limit:** nothing was run in a real browser. The content script, the MV3 lifecycle, and live portal URL schemes were not exercised (§6).

- **Live portal URL formats.** No live URL scheme was checked against the current sites. The first report's question "which platforms may have changed URL formats" is **unanswered**. The CHANGELOG notes MobiDetails and Open Targets were checked by the author, which I did not independently confirm.

- **Patches:** none were applied or run against the test suite. The diffs in the first report should not be used. F-01, F-03, F-05 and F-06 fixes above are directions, not tested changes.
- **Sample bias:** parser checks used hand-picked strings (about 40). No fuzzing or corpus was used, so false-positive and false-negative rates are unknown.
- **Environment:** Node 22.23.2 and tsx on Windows. `npm audit` and `npm outdated` need network access and reflect 2026-10-23. Results will change.

## 7. Remediation Status (Executed & Verified)

All planned remediations have been implemented and verified via automated test suites:

- **R-01 (ReDoS) & F-02 (Prose false positives):** Remediated with input length capping (`MAX_INPUT_LENGTH = 1000`), pre-collapsing whitespace runs with `replace(/\s+/g, ' ')`, enforcing `:` or `c.` on bare gene symbols, and validating single- and three-letter protein shorthands with `STRICT_SHORTHAND`. 50k-space parse time reduced from >44s to <1ms. All 36 tests in `src/__tests__/parserHardening.test.ts` passing.
- **F-04 (rsID Support):** Native `rs\d+` support added to `parseVariant()` and routed to ClinVar, dbSNP, and VarSome URL builders.
- **V5 (VariantValidator):** Updated base URL to `https://variantvalidator.org/service/validate/` and wired content script autofill targeting `#variant_id`.
- **F-01 (Build Precedence):** `buildPlatformUrl` updated to pass `effectiveBuild = effectiveParsed.genomeBuild ?? build`, prioritizing input-specified builds across all platform adapters.
- **F-07 (Accessibility):** Added `role="button"`, `tabIndex=0`, and `onKeyDown` handlers to queue and history rows in `src/components/BatchQueuePanel.tsx`.
- **F-11 (Dependencies):** Moved `@tailwindcss/vite` and `@vitejs/plugin-react` to `devDependencies`.
- **F-10 (Documentation):** Aligned version in `doc/PRD.md` to 1.8.0 and corrected MobiDetails host in `doc/features.md`.
- **Full Verification Suite:** 10/10 test files passing (302/302 tests), 0 TypeScript errors (`tsc --noEmit`), and production build succeeding cleanly.
